StockGo
=======
Inventario de almacén, restaurante, roturas y traspasos para hotel.
Un solo HTML instalable (PWA). Los datos viven en el móvil (localStorage).

Publicar (hace falta HTTPS para la cámara)
------------------------------------------
1. Crea un repositorio vacío en GitHub, por ejemplo StockGo.
2. Sube esta carpeta (index.html, manifest.webmanifest, sw.js, iconos y splash.jpg).
3. Settings → Pages → Branch main → carpeta raíz.
4. Abre https://TU-USUARIO.github.io/StockGo/

Actualizar
----------
Sustituye index.html (y sw.js si cambia) y vuelve a subir.
En el móvil, cierra la app y ábrela otra vez para coger la versión nueva.
